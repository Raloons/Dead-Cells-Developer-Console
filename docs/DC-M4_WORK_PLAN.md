# DC-M4 — console overhaul work plan

Starting HEAD: `147e23b`. DC-M3A is the preceding runtime milestone;
DC-M4 does not conflict with an existing milestone. Preserve the three
uncommitted R6 localization files as the starting point.

## Product direction

An instrument bench for mod development: fast natural commands, a shared
ambiguity-aware catalog, inventory-backed scroll shortcuts, and four optional
presentations around the proven native input field. Classic remains default.
Fancy uses original code-drawn iron/brass framing; Compact is a quick command
strip; Inspector separates output from a read-only build/catalog rail.

## Work sequence

1. Audit source, documentation, packaging, fixture gates and history.
2. Index canonical/current/English/registered names once per snapshot; load
   optional installed English POT data without distributing it.
3. Restore native scroll shortcuts and effective-tier reconciliation.
4. Shared command shortcuts, discovery, session journal and completion.
5. Native-compatible presentation plans, mode/config switching and SVG previews
   generated by the same pure layout code.
6. Contract, layout, failure and safety tests; Release/Debug builds.
7. Documentation, privacy/reference audits, deterministic packaging, installer
   and negative authorization tests; new sealed fixture and local commit.

## Boundaries

Offline development only. No game launch, input automation, authorization receipt,
production installation/save modification, remote setup, upload or push.
R6 is preserved. No authorization is inherited by a new fixture.
Runtime localization, completion/focus, native spawn and save/resume remain
separate manual acceptance gates.
