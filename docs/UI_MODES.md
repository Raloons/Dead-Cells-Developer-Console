# UI modes — retired in DC-M4.4

Classic, Fancy/Workbench, Compact and Inspector presentations were removed in
DC-M4.4. There is one traditional console overlay titled `Console`, with
`consize` panel-height control and `uimode transplant|cohesive` native input
placement. See [commands](COMMANDS.md) and the
[DC-M4.4 simplification](DC-M4.4_SIMPLIFICATION_REPORT.md).
